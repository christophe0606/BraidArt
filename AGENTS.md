# Mandatory rules

1. When importing assets or code from external projects, keep track of the source,
   license and copyright.
2. BraidArt is proprietary. Before importing third-party code or assets, ensure
   their terms permit the intended distribution and preserve their notices.
3. Don't save any secret in this repository : no password, keys etc ...
4. Avoid to test with computer use when you can do differently
   because testing with computer use is slow.
